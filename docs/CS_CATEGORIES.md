상위 메뉴의 [CS 학습](https://js05157.github.io/cs-interview/cs/)에서 운영체제·네트워크·데이터베이스·Java·Spring/JPA·자료구조·알고리즘·소프트웨어 아키텍처·DevOps·데이터 엔지니어링을 선택합니다. 각 분야는 독립 URL이 있어 북마크하거나 공유할 수 있습니다.

분야별 목록과 글 수는 게시된 CS 글의 기존 categories 메타데이터로 빌드할 때 계산합니다. 아직 게시되지 않은 비공개 원문·주제 목록·예정 글은 복사하지 않습니다. 게시된 글이 없는 분야는 0편과 안내 문장을 표시합니다. 앞으로 자동 게시된 글은 다음 배포에서 해당 목록과 개수에 반영됩니다.

홈에는 CS 학습 바로가기를, 기존 CS 종류 필터에는 분야 선택 안내를 추가했습니다. 글 목록에는 실제 분야 이름을 표시하고, CS 글 상단의 CS 학습→분야→세부분야에서 해당 분야로 돌아갈 수 있습니다. 기존 글 URL·ID·게시 날짜·본문과 Notion은 유지합니다. `/learning/`의 이전 주소는 CS 학습 화면으로 이동합니다.

로컬 공식 Pages Jekyll 빌드에서 현재 공개 글 2편·전체 HTML 22개와 분야 10개의 경로·목록·개수를 대조했습니다. Python 76개 테스트와 JavaScript 구문 검사 통과. 390px 다크 화면에서 분야 선택·운영체제 2편·네트워크 0편 표시를 직접 확인했습니다. 초기 분류 구현에서 기존 categories 배열과 Liquid 동적 키를 잘못 참조한 문제는 빌드 검사로 발견해 수정했으며 잘못된 개수로 배포하지 않았습니다.
